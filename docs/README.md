# Planning docs

Everything decided before the build.

| File | What it is |
| --- | --- |
| `website-plan.md` | The full plan: goals, site map, design direction, tech stack, quality bar, content checklist, build phases, and the prompt to start the build. |
| `mockups/Main.dc.html` | Home page, desktop. |
| `mockups/Phone.dc.html` | Home page, phone (390px), including the mobile menu. |
| `mockups/CaseStudy.dc.html` | Case study page template, desktop. |

## Viewing the mockups

The mockup files are the source of the design canvas, not standalone web pages; they need the canvas runtime to render. To see them, open the canvas:
https://claude.ai/artifact/UyoNtzAwR8yhta8WNtPrKv

The source is still useful for the build: the markup, inline styles and color tokens show exact spacing, sizes and structure.

The web copies of the plan and canvas stay the live versions. If you change either, re-export it here.
